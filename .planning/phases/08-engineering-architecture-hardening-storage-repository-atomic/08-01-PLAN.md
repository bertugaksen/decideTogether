  <action>
1. In `server/src/repositories/roomRepository.ts`:
   Define `IRoomRepository` interface:
   - `get(code: string): Room | null`
   - `save(room: Room): void`
   - `delete(code: string): void`
   - `listActive(): Room[]`
   - `cleanupExpired(maxAgeMs: number): number`
2. In `server/src/repositories/memoryRoomRepository.ts`:
   Implement `IRoomRepository` using internal `Map<string, Room>`.
3. In `server/src/repositories/sqliteRoomRepository.ts`:
   Implement `IRoomRepository` using native Node.js `node:sqlite` (`DatabaseSync` from `node:sqlite`):
   - Create table `rooms (code TEXT PRIMARY KEY, data TEXT NOT NULL, updatedAt INTEGER NOT NULL)`.
   - `save`: serializes room to JSON into `rooms` table with `updatedAt = Date.now()`.
   - `get`: reads and deserializes JSON back to `Room`.
   - `delete`: deletes by code.
   - `listActive`: returns all rooms.
   - `cleanupExpired`: deletes where `updatedAt < Date.now() - maxAgeMs`.
4. Create test suite `server/src/tests/roomRepository.test.ts` verifying CRUD operations on both memory and sqlite repositories.
  </action>
