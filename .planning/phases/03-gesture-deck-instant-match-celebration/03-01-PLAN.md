    - Signature: recordSwipe(ws: WebSocket, venueId: string, vote: 'like' | 'pass', cardIndex: number, totalCards: number): { matchedVenue?: Venue; deckExhausted?: boolean }
    - Security ASVS Level 1 controls:
      - Resolve client userId strictly from internal socket mapping this.clients.get(ws) (T-03-01).
      - Check room exists and room.status === 'swiping' (T-03-02).
      - Check if room already matched (return existing matchedVenue without re-evaluating).
      - Validate that venueId exists in room.venues array (T-03-03).
      - Store vote idempotently in room.votes[client.userId][venueId] and update progress in room.progress[client.userId] (T-03-04).
    - Relay PARTNER_PROGRESS to partner socket (exclude sender ws) with userId, cardIndex: cardIndex + 1, and totalCards. Do not disclose the vote choice (preserves privacy per T-03-05).
    - Instant Mutual Match Evaluator:
      - If vote === 'like', inspect peer's votes: const peerId = Object.keys(room.participants).find(id => id !== client.userId).
      - If peerId && room.votes[peerId]?.[venueId] === 'like':
        - Locate winning venue from room.venues.
        - Set room.status = 'matched' and room.matchedVenue = winningVenue.
        - Broadcast MATCH message with winning venue to all room participants immediately (<100ms).
        - Return { matchedVenue: winningVenue }.
    - Deck Exhaustion Evaluator:
      - Check if all participants in room.participants have cast votes for all cards (votes count >= totalCards).
      - If all finished and room.status is still 'swiping':
        - Set room.status = 'duel'.
        - Broadcast DECK_EXHAUSTED message to all room participants.
        - Return { deckExhausted: true }.

      - Partner progress is relayed to peer with cardIndex and totalCards.
      - Deck exhaustion transitions room status to 'duel' and triggers DECK_EXHAUSTED.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| WebSocket Client → RoomManager | Untrusted incoming JSON messages (START_SWIPING, SWIPE) from anonymous clients |
| Server → Peer WebSocket Client | Relayed partner progress information crossing to peer device |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Spoofing | server/src/roomManager.ts | high | mitigate | Discard any userId in payload; resolve participant identity strictly from server-authenticated socket mapping this.clients.get(ws) (ASVS V4.1) |
| T-03-02 | Tampering | server/src/roomManager.ts | medium | mitigate | Discard SWIPE actions if room.status !== 'swiping' or if room has already matched |
| T-03-03 | Tampering | server/src/roomManager.ts | medium | mitigate | Validate that venueId exists within room.venues array before registering vote or match |
| T-03-04 | Denial of Service | server/src/roomManager.ts | medium | mitigate | Idempotently record votes in room.votes[userId][venueId], discarding repeated duplicate votes for the same card |
| T-03-SC | Tampering | npm dependencies | high | mitigate | Pre-screened dependencies via package legitimacy audit; canvas-confetti verified OK |
</threat_model>
