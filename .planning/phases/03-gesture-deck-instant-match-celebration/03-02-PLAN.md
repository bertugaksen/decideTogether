    - Add state variables:
      - partnerProgress: { cardIndex: number; totalCards: number } | null (initially null).
      - matchedVenue: Venue | null (initially null).
      - isDeckExhausted: boolean (initially false).
    - Handle incoming WebSocket messages in onmessage switch:
      - 'SWIPING_STARTED': setRoom((prev) => prev ? { ...prev, status: 'swiping' } : null).
      - 'PARTNER_PROGRESS': setPartnerProgress({ cardIndex: message.cardIndex, totalCards: message.totalCards }).
      - 'MATCH': setMatchedVenue(message.venue); setRoom((prev) => prev ? { ...prev, status: 'matched', matchedVenue: message.venue } : null).
      - 'DECK_EXHAUSTED': setIsDeckExhausted(true); setRoom((prev) => prev ? { ...prev, status: 'duel' } : null).

      - startSwiping: useCallback(() => send({ type: 'START_SWIPING' }), [send]).
      - sendSwipe: useCallback((venueId: string, vote: 'like' | 'pass', cardIndex: number, totalCards: number) => send({ type: 'SWIPE', venueId, vote, cardIndex, totalCards }), [send]).
    - Return partnerProgress, matchedVenue, isDeckExhausted, startSwiping, sendSwipe from useRoomSocket.
