    Implement recordDuelTap, concludeDuel, and resolveDuelWinner in server/src/roomManager.ts:

    1. recordDuelTap(ws: WebSocket, cumulativeTaps: number): void
       - Resolve client via this.clients.get(ws) (T-04-01).
       - Validate room exists, room.duelState exists, and room.duelState.status !== 'finished'.
       - Boundary check: const now = Date.now(). If now < room.duelState.startTime (taps sent during countdown) or now > room.duelState.startTime + room.duelState.durationMs + 400 (late tap injection after buzzer grace), drop packet silently (T-04-02, T-04-03).
       - Anti-cheat clamp: const currentScore = room.duelState.scores[client.userId] || 0. If cumulativeTaps - currentScore > 30, clamp cumulativeTaps to currentScore + 30 (prevents macro bots sending 1000 taps in one packet per T-04-02).
       - Monotonic update: room.duelState.scores[client.userId] = Math.max(currentScore, cumulativeTaps).
       - Broadcast DUEL_PROGRESS with room.duelState.scores to room participants.

    2. concludeDuel(roomCode: string, forcedWinnerId?: string): void
       - Retrieve room. If !room || !room.duelState || room.duelState.status === 'finished', return early.
       - Clear room.duelState.timer if present.
       - Set room.duelState.status = 'finished'.
       - Determine winner:
         - If forcedWinnerId is provided, winnerId = forcedWinnerId.
         - Else compare participant scores:
           - If score1 > score2: winnerId = user1.
           - If score2 > score1: winnerId = user2.
           - If score1 === score2 (exact tie): winnerId = Math.random() < 0.5 ? user1 : user2, tieBroken = true (DUEL-04).
       - Call const winningVenue = this.resolveDuelWinner(roomCode, winnerId).
       - If winningVenue:
         - Set room.status = 'matched', room.matchedVenue = winningVenue, room.lastActiveAt = Date.now().
         - Broadcast MATCH message with venue: winningVenue and duelResult: { winnerId, scores: room.duelState.scores, tieBroken }.

    3. resolveDuelWinner(roomCode: string, winnerId: string): Venue | undefined
       - Hierarchical fallback per D-04 / DUEL-04:
         a) Winner's likes: Query room.votes?.[winnerId] for votes === 'like'. If liked venues found in room.venues, sort descending by rating (b.rating - a.rating) and return highest-rated liked venue.
         b) Winner passed on all: Query peer's likes from room.votes?.[peerId]. If liked venues found, sort descending by rating and return highest-rated peer liked venue.
         c) Both passed on all: Fall back to room.venues[0] (top deck venue).

    Expand server/src/tests/duel.test.ts:

      - concludeDuel resolves winner based on higher tap count.
      - concludeDuel breaks exact score ties via fair coin toss with tieBroken: true.
      - resolveDuelWinner returns winner's liked venue, falls back to peer's liked venue if winner has 0 likes, and falls back to deck[0] if both have 0 likes.
